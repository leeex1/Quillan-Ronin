## Skill Invocation Pattern

All skills follow the same invocation pattern through MCP:

```python
# 1. Identify the skill
skill_name = "cross_modal_generation"
mcp_server = "QuillanMedia"
tool_name = "media_image_brief"

# 2. Invoke through MCP
result = tools.QuillanMedia.media_image_brief(
    objective="Generate a futuristic cityscape",
    style="cyberpunk",
    composition="rule of thirds",
    palette="neon"
)

# 3. Receive structured result
print(result["status"])  # "OK"
print(result["objective"])  # "Generate a futuristic cityscape"
print(result["content"])  # [...]
```

## Skill Validation Protocol

Each skill skill directory must contain:
- `SKILL.md` - Skill definition with metadata
- Supporting documentation files
- Mapping to at least one MCP tool
- Validation through `QuillanOntology` schema

## Skill Discovery

To discover available skills:
1. Check `00_SKILLS_REGISTRY.md` for the complete list
2. Use `tools.QuillanThinkingEngine.quillan_think(query="skill discovery")` to search
3. Use `tools.QuillanCouncil.council_deliberate(query="skill capabilities")` for council deliberation

## Skill Maintenance

Skills are maintained through the `upgrade_and_sync_mcp.py` script which:
1. Scans all skill directories for SKILL.md files
2. Maps skills to MCP tools
3. Updates `mcp_tool_registry.json`
4. Runs E2E verification

Run: `python upgrade_and_sync_mcp.py --reindex-skills`
